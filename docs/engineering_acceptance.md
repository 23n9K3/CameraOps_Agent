# AI-CPL 工程验收清单

## 可执行证据

| 范围 | 验证方式 |
| --- | --- |
| RAW Reader | 已知字节向量覆盖 MIPI RAW10/12/14、大小端、8/16 位容器、行填充、截断和布局校验；实际 NEF 解码输出 4284×2844 RGGB |
| Capture Simulator | 种子与曝光可重复、增益与曝光分别改变码值、噪声统计、缺陷掩码和 Ground Truth 对齐 |
| Registration | 已知平移验证 ECC 和坐标方向，低纹理回退，实际闭环尝试相位相关初始化 |
| Multi-frame Denoising | 单帧对照、融合权重可重建输出、同色坏点修正和合成暗部真值比较 |
| HDR | 数值夹具验证多曝光重建和饱和通道降权，工程场景检查恢复目标 |
| Ghosting | 移动纹理验证 Farneback、掩码、参考帧权重和重处理后真值误差 |
| Agent Workflow | LangGraph 节点与工具调用、输入产物关联、重试、超时和实验预算 |
| Debugging 闭环 | 验证实际故障、改变处理参数、发布新产物，并独立评测首轮与修复输出 |
| IQ Evaluation | 解析输入核验 PSNR、SSIM、裁剪，检查无参考输入返回 `null` 与原因 |
| SQLite 与 Optuna | 真图试验、历史回读、相似性准入、失败试验记录、Pareto 持久化和基线比较 |
| Streamlit | AppTest 覆盖上传、采集、处理、实时工作台、故障复核、优化和报告导出入口 |
| Agent Benchmark | 十类场景配对比较五种策略，输出逐任务证据、统计表、曲线与消融 |

验收修复了独立 RAW 文件输入生成的摄影产物缺少输入 Artifact ID 时，IQ 评估无法继续的问题。该路径仍能计算无参考质量指标。另在指标 schema 层校验数值是否存在与有效标记是否一致。

## 尚未完成或尚未验证

| 状态 | 功能与当前边界 |
| --- | --- |
| 尚未实现 | Bayer 错配推断与自动修复。Benchmark 三个相应任务在五种方法下均应按实际条件判定。 |
| 尚未实现 | 过曝、欠曝、高噪声、运动模糊、偏色、黑电平错误和裁剪的独立 Camera Debugging 诊断与闭环修复。现有摄影算法能处理部分曝光和噪声问题，自动故障闭环实装覆盖配准与鬼影。 |
| 尚未实现 | 合格斜边的 MTF50 测量流程与靶标。IQ 字段含缺失原因。盲噪声与鬼影是估计量。 |
| 部分实现 | 已接入 DeepSeek 做目标理解与策略选择，使用模拟 HTTP 响应验证，在线验收需要 API 密钥。PyTorch、torchvision 学习式摄影算法未接入。 |
| 部分实现 | 工具白名单已接入实际的采集、场景、摄影、评估和诊断。原设计的所有细粒度算法尚未逐个独立注册为 Agent 工具。 |
| 部分实现 | 全局配准模型覆盖平移，Farneback 用于局部运动分析。强旋转、视差、滚动快门和稠密几何补偿尚未实现。 |
| 尚未实现 | 硬件采集和真实传感器标定。模拟使用简化的全局快门及传感器噪声模型。 |
| 尚未验证 | 各厂商相机与 RAW 封装的广泛兼容性。实测一组 Google HDR+ DNG 和一个 Nikon NEF 可读，已知 Canon CR2 样本由 LibRaw 报数据错误。 |
| 尚未验证 | 真实 RAW 数据集上的标定 IQ、跨场景优化泛化、其他操作系统与 Python 版本、长时并发压力。当前 Optuna 多目标评分要求带匹配真值的 P2 Burst。 |

验收结论针对记录的执行环境、输入和门槛。生产使用实测经单独验收的工具进程隔离，Benchmark 使用统一进程内节省启动开销。
