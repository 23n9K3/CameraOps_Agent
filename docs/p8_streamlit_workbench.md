# P8 Streamlit 可视化工作台

从项目根目录启动 `python -m streamlit run app.py`。默认使用当前目录下的 `artifacts/` 和 `artifacts/experiments.sqlite3`。CLI 与 UI 保存的产物共用同一套目录和报告格式。

| 页面 | 使用方式 |
| --- | --- |
| 总览 | 查看工作流总数、完成率、摄影实验与优化试验数，以及最近实测结果 |
| RAW 数据集 | 预览单帧、上传有序 RAW 序列、查看 Bayer 码值直方图并导出 RAW 与布局 |
| 采集规划 | 输入目标，生成基于当前场景的 CapturePlan，按计划模拟采集新的 Burst |
| 计算摄影 | 从本地 Burst 运行 Night、HDR 或 Motion-aware，检查中间结果并下载最终 PNG |
| Camera 调试 | 阅读故障假设、证据和修复参数，对比前后裁剪区域，从落盘影像复核选定的假设 |
| Agent 工作台 | 启动 LangGraph 闭环，跟踪节点、工具、返回值、迭代、耗时、诊断和最终产物 |
| 实验中心 | 查询 SQLite 历史，运行 Optuna、查看 Pareto 前沿和目标对照、下载 HTML 与 CSV |
| 报告中心 | 查看工作流与优化报告，导出 JSON、CSV、HTML 和最终 PNG |

## Agent 执行事件

点击 **运行 Agent 工作流** 后，工作流在后台执行。`node_started` 与 `node_finished` 记录真实节点起止，`tool_started` 与 `tool_finished` 记录每次工具尝试的起止、参数关联的产物、成功返回与异常。工作台在运行期间每 500 ms 读取新事件并更新，终态停止轮询。工具返回结构化结果和 Artifact ID，图像通过产物库读取。

工作台默认选择最近导入的实拍 RAW 序列，并显示该序列最近完成的处理结果。首次使用且暂无实拍数据时，可前往 RAW 数据集导入同场景的 RAW 连拍。模拟采集入口位于采集规划。复测完成后可开启「检查局部、掩码与融合权重」，并下载最终 PNG。

局部对比对两张图应用同一组像素坐标，可选择 1×、2×、4× 或 8× 放大并调整位置。RAW 曝光直方图基于原始 Bayer 码值，摄影对比直方图基于界面所选局部的显示亮度。融合权重可查看各颜色通道或 RGB 平均值。

工作台的实时时间线属于当前浏览器会话。已完成的任务与工具轨迹可在报告中心重新查看。优化使用带校准 Ground Truth 的合成 Burst。相机 RAW 容器的兼容性取决于 LibRaw。
